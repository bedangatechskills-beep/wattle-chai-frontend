One element, four parts

<a href="#menu" > See the menu </a> attribute opening tag content closing tag element = opening tag + content + closing tag

How to play

  • Tag = the name in angle brackets, like <p>. It tells the browser what something is.
  • Remove tag only keeps the words but loses the tag. You see what the tag gives.
  • Remove whole element takes the tag and its content away.
  • Attribute = extra information inside the opening tag, name="value".
  • Nesting: elements sit inside elements. The indents in the code show it.
  • <img> and <meta> have no content, so no closing tag.
